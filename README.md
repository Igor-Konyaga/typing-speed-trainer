## Typing Speed Trainer

A desktop application built with **Python** and **Tkinter** to help users improve their typing speed and accuracy.

### Features
- Random or custom text for typing practice
- Words per minute (WPM) calculation
- Typing accuracy and error tracking
- Automatic timer
- Start and stop controls
- Dark-themed interface

### Technologies
- Python 3
- Tkinter

### How to run

```bash
git clone https://github.com/Igor-Konyaga/typing-speed-trainer.git
cd typing-speed-trainer
python3 main.py
```
