# Typing Speed Trainer

A simple desktop application built with Python and Tkinter that helps users improve their typing speed and accuracy.

### Features
- Random text or custom text mode.
- Real-time typing speed calculation (WPM).
- Typing accuracy and error tracking.
- Timer that starts automatically when typing begins.
- Start and stop training at any time.
- Simple and user-friendly interface with a dark theme.

### Technologies
- Python 3
- Tkinter

### How to Run

1. Clone the repository:
   ```bash
   git clone YOUR_REPOSITORY_URL
   ```
2. Navigate to the project directory:
   ```bash
   cd TypingTrainer
   ```
3. Run the application:
   ```bash
   python3 main.py
   ```
